## What this change does

Adds a `## TL;DR` section (between `## PR` and `## Coder's PR
description`) with three required H3 sub-sections (`### What shipped`,
`### Downstream contract`, `### Decisions worth knowing`),
auto-filled by mirroring identically-named sub-sections from the
coder's PR body; absent sub-sections render a TBD placeholder. The
coder prompt is updated to instruct PR bodies to carry the three
sub-sections. Because the new section sits above the existing
`cycle_log_summary` strip boundary, downstream worker prompts pick up
the TL;DR content with zero changes to the summary function or its
callers.
